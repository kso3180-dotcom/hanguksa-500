# 한능검 심화 기출 500

한국사능력검정시험 심화 제71회~제80회 기출 500문항으로 공부하는 웹 앱입니다.

- **실전 모의고사**: 회차별 50문항, 80분, 자동 채점과 급수(80점 1급 · 70점 2급 · 60점 3급)
- **시대별 풀이**: 9개 시대 중 골라서, 풀자마자 정답·해설 확인
- **랜덤 10문제**, **한 문제씩 타이머**(45·60·90초), **오답노트**
- 학생은 선생님이 준 **개인 코드**로 시작하고, 결과는 선생님 구글 시트로 자동 제출됩니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 전체 (화면·기능) |
| `config.json` | `scriptUrl`: 구글 시트 Apps Script 웹 앱 주소 |
| `data/questions.json` | 문항 데이터 (회차·번호·정답·배점·시대·해설) |
| `img/` | 문항 이미지 500장 + 72회 47~48번 공통 지문 |
| `apps_script/Code.gs` | 구글 시트에 붙여 넣을 기록용 스크립트 |

## 출처

문제·정답: 국사편찬위원회 한국사능력검정시험 심화 제71~80회.
시대 분류와 해설은 학습용으로 따로 정리한 것입니다.
